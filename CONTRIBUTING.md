# Contributing to PG Proxy

Thank you for contributing to Datadog's PG Proxy. We accept contributions in many
forms.

Before you start, read
[Contribute to PG Proxy](docs/site/src/content/docs/how-to/contributing.md) in the
documentation. It covers reporting bugs, opening an issue before non-trivial
changes, development setup, the checks to run before a pull request, and our
guidelines for commits and pull requests.

Do not report security vulnerabilities in public issues or pull requests.
Email security@datadoghq.com instead.
