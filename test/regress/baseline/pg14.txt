# PostgreSQL 14 regression tests that pg-proxy skips or is expected to fail.
#   skip <test>  # <cause>  Left out of the schedule: pg-proxy cannot pass it by design.
#   fail <test>  # <cause>  Runs and is expected to fail; listing a test that passes fails the run.
#                           A by-design failure that later tests depend on is a fail entry, so it
#                           still creates their objects.
# Any other failing test fails TestInstallcheckThroughProxy. PG_PROXY_REGRESS_UPDATE=1
# rewrites the fail entries from a run, keeping skip entries and reasons.
#
# Causes:
#   session-reset        SET, SET ROLE and SET SESSION AUTHORIZATION are undone after every
#                        transaction: releasing the backend connection runs RESET ALL and
#                        resets the role.
#   backend-reuse        Backend connections outlive client sessions, so temporary objects,
#                        cursors, prepared statements and loaded modules carry over between
#                        clients, and a test cannot rely on a fresh backend.
#   fastpath             FunctionCall (fastpath) messages, used by libpq's large-object
#                        functions, are not supported.
#   login-trigger        Login event triggers fire when the proxy opens a backend connection,
#                        not when a client connects.
#   depends-on-skipped   Uses objects that a skipped test creates.
#   switchover-hint      pg-proxy appends a leader switchover hint to read-only transaction
#                        errors.
#   statement-names      pg-proxy renames named prepared statements on backend connections,
#                        which pg_prepared_statements and some error messages show.
